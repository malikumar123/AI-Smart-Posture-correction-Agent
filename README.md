# 🧍 AI Smart Posture Correction Agent

An AI-powered Python application that monitors body posture in real time using a webcam. The project leverages MediaPipe Pose and OpenCV to detect posture and provide visual feedback, helping users maintain healthier sitting habits.

---

## 📖 Overview

Poor sitting posture can lead to neck pain, back pain, and fatigue. This project demonstrates how computer vision and AI can be used to analyze human posture in real time.

---

## ✨ Features

- ✅ Real-time posture detection
- ✅ Live webcam processing
- ✅ Pose estimation using MediaPipe
- ✅ Visual pose landmarks
- ✅ Lightweight and easy to run
- ✅ Beginner-friendly project structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/malikumar123/AI-Smart-Posture-correction-Agent.git
```

### Navigate to the project

```bash
cd AI-Smart-Posture-correction-Agent
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### Install dependencies

```bash
pip install opencv-python mediapipe
```

---

## ▶️ Run the Project

```bash
python posture_agent.py
```
